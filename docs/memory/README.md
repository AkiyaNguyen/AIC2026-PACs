| Location | Contents |
|----------|----------|

## Conventions

- English for repo-authored notes.
- Paper summaries: factual + clarification tables for easy misreadings only.
- Discussion notes: short, actionable; link to `SUMMARIES.md` instead of pasting papers.
- After a useful design chat, update `DiscussionNotes.md`. Agents should read it before inventing architecture.
